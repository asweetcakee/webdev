## Full Stack Open 2025 — Part 2
This directory contains my **solutions to Part 2 exercises** of the [Full Stack Open 2025](https://fullstackopen.com/en/part2) course, focusing on **frontend communication with a server** using React and REST APIs.

## Exercises
| Exercise Group        | Range       | Description                                     |
|-----------------------|-------------|-------------------------------------------------|
| `course information`  | 2.1 – 2.5   | Component decomposition, props, state           |
| `phonebook`           | 2.6 – 2.17  | CRUD, state handling, controlled inputs, API    |
| `countries`           | 2.18 – 2.20 | Data fetching, filtering, conditional rendering |

## Clone and run locally

Clone this repository:
```bash
git clone https://github.com/asweetcakee/webdev.git
cd webdev
git checkout fullstackopen
```

To start each exercises:

**course information**

Choose any exercise from 2.1 - 2.5 and edit `cd part2/XXX/course-information-step-XXX` command.
```bash
cd part2/2.1/course-information-step-6
npm install
npm run dev
```

**phonebook**

```bash
cd part2/2.6-2.17/phonebook
npm install
npm run dev
```

**countries**
```bash
cd part2/2.18-2.20/countries
npm install
npm run dev
```
