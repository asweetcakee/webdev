## Full Stack Open 2025 — Part 1
This directory contains my **solutions to Part 1 exercises** of the [Full Stack Open 2025](https://fullstackopen.com/en/part1) course. The focus is on the **fundamentals of modern React**, including component composition, props, state, event handling, and basic refactoring.

## Exercises
| Exercise Group       | Range       | Description                                                                 |
|----------------------|-------------|-----------------------------------------------------------------------------|
| `course information` | 1.1 – 1.5   | Intro to components, props, composition, and rendering data                 |
| `unicafe`            | 1.6 – 1.11  | State, event handling, and aggregating data via button clicks               |
| `anecdotes`          | 1.12 – 1.14 | More advanced state usage, conditional rendering, and selecting random data |

## Clone and run locally
Clone this repository:
```bash
git clone https://github.com/asweetcakee/webdev.git
cd webdev
git checkout fullstackopen
```

To start each exercises:

**course information**
Choose any exercise from 1.1 - 1.5 and edit `cd part1/XXX/course-info-step-XXX` command.
```bash
cd part1/1.1/course-information-step-1
npm install
npm run dev
```

**unicafe**
Choose any exercise from 1.6 – 1.11 and edit `cd part1/XXX/unicafe-step-XXX` command.
```bash
cd part1/1.6/unicafe-step-1
npm install
npm run dev
```

**anecdotes**
Choose any exercise from 1.12 – 1.14 and edit `cd part1/XXX/anecdotes-step-XXX` command.
```bash
cd part1/1.12/anecdotes-step-1
npm install
npm run dev
```
